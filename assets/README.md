# Assets

Place your app icons and splash images here:

- `icon.png` – 1024×1024 app icon
- `adaptive-icon.png` – Android adaptive icon foreground
- `splash-icon.png` – splash screen image
- `favicon.png` – web favicon

You can generate these quickly with [https://www.appicon.co](https://www.appicon.co) or Expo’s icon tools.

Until you add real images, Expo will use defaults or show warnings. The app still runs.
